# my-board

Claude Code 화면 옆에 띄우는 나만의 Claude 보드입니다.

- **사용량**: 5시간·주간 한도와 컨텍스트를 3중 원그래프로, 초기화까지 남은 시간과 함께 보여 줍니다. 80%·95%를 넘으면 알림이 뜹니다.
- **컨텍스트 구성**: 대화·도구·스킬이 컨텍스트를 얼마나 차지하는지 막대그래프로 보여 줍니다.
- **최근 6시간 추이**: 사용량이 어떻게 움직였는지 선그래프로 보여 줍니다.
- **빠른 전환**: 모델, 답변 스타일, 권한 모드를 버튼 하나로 바꿉니다.
- **연결된 데이터**: 지금 쓸 수 있는 커넥터를 그룹별로 보여 줍니다.
- **지금 하는 일**: Claude가 작업 중인지, 몇 초째인지, 할 일 단계(✔ ▶ ○)와 최근 동작을 보여 줍니다.
- 입력창 아래 상태줄에 사용량 한 줄 요약이 항상 표시됩니다. 패널을 닫았다면 `/board`로 다시 엽니다.

## 세컨드 브레인

보드의 "세컨드 브레인" 버튼이나 `/brain`으로 여는 두 번째 패널입니다. 이 컴퓨터에 저장된 Claude Code 대화(`~/.claude/projects`)를 읽어서:

- 작은 모델(Haiku)이 대화마다 주제 태그 3~5개와 한 줄 요약을 한 번 붙이고,
- 같은 주제나 같은 커넥터를 쓴 대화끼리 선으로 이은 **연결 지도**,
- **지금 대화와 이어진 대화**, **자주 다룬 주제**, **대화 목록**을 보여 줍니다.

맨 위의 **일잘러 점검** 카드는 대화들로 내가 일하는 방식을 비춰 봅니다:

- **맥락 이어가기**: 새 대화가 앞선 대화와 같은 주제로 이어지는 비율
- **일의 흐름**: 주제로 이어진 대화 묶음 수와 따로 떨어진 대화 수
- **중요한 일 비중**: 중요도 4~5인 일에 쓴 대화량의 비율
- **중요도 × 들인 대화량** 4칸 그래프(핵심에 집중 / 챙겨야 할 중요한 일 / 시간 많이 든 가벼운 일 / 가벼운 일)와 일의 종류별 비중, 수치에서 뽑은 짧은 제안

중요도(1~5)와 일의 종류는 태그를 붙일 때 같은 모델이 함께 매깁니다. 기준은 **내 우선순위 파일**입니다: 처음 정리할 때 `priorities.example.md`가 `~/Library/Application Support/my-board/priorities.md`로 복사되고, `/priorities`로 열어 핵심 사명·지금 시기 우선순위·마감·미뤄지지 않게 볼 일을 적어 두면, 그 기준으로 중요도를 매기고 다가오는 마감이나 오래 손 안 댄 일을 점검 카드에서 알려 줍니다. 이 파일은 저장소에 올라가지 않습니다.

태그와 요약은 이 컴퓨터의 플러그인 저장소에만 남고, 저장소(GitHub)에는 올라가지 않습니다. 처음 정리할 때 대화 수만큼 사용량이 조금 들고, 이후에는 새 대화나 많이 길어진 대화만 다시 정리합니다. claude.ai 웹·앱 대화는 컴퓨터에 저장되지 않아 포함되지 않습니다. 대화 읽기에는 macOS 기본 `/usr/bin/python3`를 씁니다.

커넥터 이름표는 `hooks/register.tsx`의 `CONNECTORS` 목록에 직접 적혀 있습니다. 새 커넥터는 "새 커넥터 ○○○○"로 나오니 그때 한 줄 추가하세요.

## 바탕화면 창

보드를 Claude 밖의 독립 창으로도 띄울 수 있습니다. 한 번만 실행하세요:

```bash
bash window/make-app.sh
```

`~/Applications/Claude 보드.app`과 바탕화면 아이콘이 생기고, 누르면 Chrome의 앱 창(탭 없는 창)으로 보드가 열립니다. 세션마다 모드가 `~/Library/Application Support/my-board/sessions/<세션>.js`에 자기 값을 써 두고, 창은 4초마다 다시 읽어 바뀐 것이 있을 때만 다시 그립니다. 처음 화면은 **전체**(계정 사용량, 열린 세션 목록, 일잘러 점검, 세컨드 브레인)이고, 세션을 누르면 그 세션의 진행 상황만 따로 봅니다. Claude Code가 꺼져 있으면 마지막 값과 "마지막 갱신 ○분 전"이 표시됩니다. 창은 보기 전용이고, 설정 바꾸기는 Claude 안의 보드에서 합니다. Google Chrome이 필요합니다.

## 설치

터미널의 Claude Code 프롬프트에서:

```
/plugin install my-board --marketplace David-KIM-sol/my-board
```

셸에서:

```bash
claude plugin install my-board --marketplace David-KIM-sol/my-board
```

데스크톱 앱(`/plugin`이 안 되는 곳)에서는 입력창 옆 + → Plugins → Add marketplace에 `David-KIM-sol/my-board`를 넣고 Add plugin을 누릅니다.
